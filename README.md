## 📌 About This Repository

Python Lab is a collection of programming exercises, laboratory tasks, experiments, and mini-projects designed to develop practical Python skills.

Rather than focusing only on syntax, the goal is to understand **how programming concepts work, why they matter, and how they can solve actual problems.**

### 🎯 Objectives

- Develop strong Python programming fundamentals.
- Improve logical thinking and problem-solving abilities.
- Understand Object-Oriented Programming (OOP).
- Explore scientific and numerical computing.
- Work with real-world datasets.
- Apply Python to mathematical and engineering problems.
- Build a foundation for Machine Learning and Artificial Intelligence.

## 💡 Learning Philosophy

My approach to learning programming is based on four principles:

1. **Understand:** Learn the underlying concept, not just the syntax.
2. **Implement:** Write code independently.
3. **Experiment:** Test different approaches and explore edge cases.
4. **Apply:** Connect programming concepts to practical problems.
